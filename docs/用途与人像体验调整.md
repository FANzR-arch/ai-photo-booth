# 用途与人像体验调整

2026-09-22 原始调整记录。当前分类已于 2026-09-30 改为人像写真、职业形象、生日纪念、婚礼写真、亲友合照、旅行日常、创意艺术；具体数量与维护入口见 README。下方其余内容为当时的实现与验证记录。

## 已实现

- 原选片页使用四类用途。现已按拍摄内容重新分组，每款只出现一次，自定义模板在「其他模板」，空分类隐藏。
- 新增「自然的你」，共 22 款启用风格。默认保留原衣着与姿态，用光线、背景和轻微修饰改善照片。
- 电影、职场、杂志、胶片提示词减少人物重建；节日款明确标注换装。保留每个人的身份、年龄、肤色、眼镜和辨识特征，不夸张磨皮瘦脸。
- 单人和合照提供对应拍摄指导，拍摄确认时提醒检查闭眼与遮挡；成片页提示对照原图确认自然程度。
- 新会话自动保存推荐相纸，用途随会话保存。自然棚拍默认留白、合照推荐拍立得、纪念用途推荐票根。用户编辑后刷新和重新启动不会被推荐值覆盖。
- 所有边框和文字编辑继续保留；字体、字号、颜色和对齐收在「更多文字调整」。

## 维护位置

- `config/styles/styles.json`：内置风格与提示词。
- `packages/shared/photo-categories.ts`：当前页面分类、排序与原用途映射。
- `packages/shared/portrait-experience.ts`：兼容历史会话的用途、拍摄指导、相纸推荐。
- `config/styles/portrait-migration.json`：本轮升级前内置提示词的 SHA-256。服务启动时只升级精确匹配的旧提示词，保留后台自定义提示词、样图、名称和开关，不改已有会话快照。
- 配置由服务启动时加载，已有运行实例需要重启才能加载新提示词。

## 验证与限制

- TypeScript / Vite 构建通过，58 项自动化测试通过；包含用途过滤、无提前创建会话、推荐相纸持久化、升级幂等及自定义提示词保护。
- 浏览器检查了桌面用途页、合照指导、原片确认、本地演示生成和相纸编辑。
- 浏览器使用独立 demo 数据目录，不访问现有运营数据，不调用付费生成。
- 自然棚拍复用已有棚拍氛围参考图；其他样图同样用于表现风格，不是新提示词的实测结果。多人样片和同人对照仍待真实生成验收，不能把提示词约束当作相似度保证。
- 实拍验收应使用获授权的原照，覆盖不同年龄、眼镜、发型和双人场景；逐张检查身份、表情、人数、手部与遮挡。异常结果不能作为推荐样片。

按用户要求，前台、取图页、设备工作台和功能概览页已清理“模拟”“演示”等界面文案，使用“照片效果”“选择照片”“确认取图”等表述。内部模式标识及处理逻辑不变，真实支付、打印机及付费人像验证仍未接入或执行；维护文档保留此事实说明。
