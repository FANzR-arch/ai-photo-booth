## 等待阶段

`GenerationPreview.tsx` 展示本次原照片，使用 contain 完整显示，不裁脸、不重复镜像。照片上方标记“原照片”，下方状态胶囊显示“重绘中”；本地 demo 显示“效果制作中”。动画为淡扫光、旋转小符号和呼吸圆点，非虚构百分比。显示进入等待页面后的实际秒数，40 秒后切换为持续处理中提示。系统偏好减少动态效果时关闭动画。

成功后进入结果页；失败／结果未知时保留原图，停止动画；重试重新计时；结束体验清除原照片。刷新恢复任务时，从仅本机的 originalUrl 接口恢复原图；只有不含原图的历史会话显示占位说明。不会额外将个人照片写入浏览器存储。
