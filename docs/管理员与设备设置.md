# 管理员与设备设置

## 使用方式

Mac 安装或更新会自动创建桌面「启动拍照亭.command」。双击打开首页 → 设备设置 → 输入密码 → 填写自己的 Seedream API 密钥与模型 ID → 保存配置 → 返回拍照亭。

首次使用默认密码 **88888888** 解锁，然后在工作台「管理员密码」中输入当前密码和新密码（至少 8 位，不能再用默认密码）完成修改；修改后其他已打开的工作台需要重新登录。登录页不显示任何密码提示；登录后若仍在使用默认密码，「管理员密码」一栏会提醒修改。忘记密码时，用维护菜单 5（Mac）或 `npm run admin:password -- --default` 恢复默认密码 88888888，再登录修改；`npm run admin:password` 不带参数时可在终端直接设置新密码。

API 保存后立即用于下一次生成，无需重启。输入框清空，已保存密钥仅显示掩码；留空保存时保留原密钥。保存与检查本机配置均不发起生成，也不能验证供应商额度或模型权限。维护菜单的演示模式仍保持演示，日常桌面入口始终使用真实生图模式。

## 实现边界

- 桌面入口手动启动，固定端口与持久数据，重复启动打开已有服务。不注册开机或登录自启。Terminal 窗口可以最小化，Control+C 停止。
- 初次设置只允许本机、同源 JSON 请求。原子创建密码文件避免多个实例同时设置覆盖；已经设置时返回冲突，网页转为输入已有密码。
- 密码用 scrypt 哈希。登录 Cookie 为 HttpOnly / SameSite=Strict；管理接口逐次鉴权。闲置 10 分钟、最长 8 小时、连续错误限流、退出/重启/密码重置失效。
- API 复用原有 `.env` 原子写入器，保留端口和取图地址；成功写盘后才替换当前应用的凭据，不修改进程全局环境。生成期间拒绝保存。
- 摄像头选择、拍照流程沿用既有实现；未新增收费、自动打印或公网取图。
