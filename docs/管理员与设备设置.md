# 管理员与设备设置

本次沿用现有工作台与拍照流程，新增后台访问保护、本机 API 配置、摄像头选择。**默认启动仍打开拍照首页，用户主动点击“设备设置”进入后台。** 不接真实支付，不发送付费生图请求，不实现自动打印或公网取图。

## 已实现

- 本机设置和重置密码：Mac 菜单选 5，或项目目录 `npm run admin:password`。密码至少 12 个字符，输入不回显，无默认密码，无网页首次抢注入口。
- 管理接口统一鉴权：登录后才能读取模板完整提示词、订单、生成记录或修改配置。顾客拍照与限时取图沿用已有权限规则。
- 闲置 10 分钟自动锁定，单次会话最长 8 小时；登出、重启或密码重置使会话失效。5 次错误后在 15 分钟窗口内限流。后台状态轮询不会延长闲置时间，实际操作通过活动请求延长。
- 密码存储为 scrypt 哈希。会话随机生成并保留在服务端内存，Cookie 使用 HttpOnly / SameSite=Strict。工作台仍仅允许 localhost 访问，保留来源检查。
- 已保存 API 密钥只返回掩码；可更新模型，密钥留空时保留原值。复用原有 .env 原子写入逻辑，保留端口和取图地址。保存后需重启，生成进行中禁止修改。
- 配置检查只确认本机保存与加载状态，不宣称供应商授权、余额或真实成片已验证。
- 管理员主动开启摄像头预览后可选择外接设备、检查实际分辨率并保存。退出工作台关闭预览并释放摄像头。拍照页使用已指定设备；设备不可用不自动换用其他镜头。

## 客户 Mac 更新

请现场 AI 沿用 `/Users/itadmin/Applications/ai-photo-booth`，先正常停止本项目服务，保留并备份 `.env`、`data/`，确认 Git 工作区无未处理的改动。随后：

```bash
cd "$HOME/Applications/ai-photo-booth"
git pull --ff-only origin main
bash scripts/macos/prepare.sh --update
```

完成停止和备份检查后，按提示输入 UPDATE。重新运行 `bash mac-booth.command`，先选 5，由用户在本机终端输入两次密码；不要把密码发到 AI 聊天里。再次打开菜单选 1 进行免费联调，或在已有明确授权与正确配置时选 3。

程序启动后保持首页；用户主动进入“设备设置”解锁。设置 UGREEN 后用真实预览核对镜头。随机联调端口每次变化，摄像头偏好不会跨网址迁移；进入正式固定端口后请重新选择一次。
