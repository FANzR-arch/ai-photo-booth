# 无人值守首版上线

更新：2026-10-05。目标：中国大陆门店，Mac 无人值守，AI 生图、打印，手机连接店内 Wi-Fi 取图。甲方已确认 **现场先收费再使用拍照亭**，程序内不设付款环节；原自助支付接入方案已取消。需求与推进顺序以 [甲方需求对照与更新规划](甲方需求对照与更新规划.md) 为准，打印参数采集见 [客户对接：打印](客户对接-打印.md)。

## 已具备

- 拍照确认后直接生成；生成开始即发放手机取图码，包含 AI 成片与拍摄原片。
- 管理员密码、接口鉴权、本机配置、摄像头选择和测试模式开关。
- Mac 点击打印：持久化打印任务，重复点击、刷新和重启不重复出纸；结果未知不自动重打。
- 本地 SQLite、固定端口、单任务生成、重复提交保护、未知生成结果不自动重试、局域网凭证取图。
- 新照片生成完成后 10 分钟删除，查看或下载不会延期。

## 剩余工作

| 顺序 | 工作 | 完成条件 |
| --- | --- | --- |
| 1 | 确定纸张与打印规则 | 纸张尺寸、份数、裁切方式与补打规则明确 |
| 2 | 自动打印及故障恢复 | 成片就绪后自动提交；缺纸、离线、失败及结果未知有可执行的处理方式 |
| 3 | 启动与恢复 | 浏览器与服务在 Mac 登录后可恢复；服务重启可恢复已知任务，未知结果不盲目重试 |
| 4 | 现场验收后切换营业 | 真实生成、实物打印、手机取图，以及异常恢复均通过；留存版本和回退方法 |

当前 `启动拍照亭.command` 依赖保持终端运行，运行期间防闲置睡眠，但没有登录后启动、服务异常退出恢复和浏览器恢复配置。Mac 登录后恢复与断电后自动恢复是不同能力，后者还受系统登录、安全设置和硬件限制影响，必须现场验证。

## 开发与验收约束

- 生成和打印分别记录状态。提交打印队列或获得任务编号，不能冒充已经交付实物。
- 生成明确失败、超时结果未知、打印明确失败和打印结果未知分别处理；不能统一自动重试，以免重复调用 API 或出纸。
- 手机取图期限与打印任务期限分开管理；不能无限延长照片留存，也不能让清理任务删掉正在交付的文件。
- 打印配置从受保护的本机后台读取。调用系统命令使用参数数组，不拼接顾客输入。
- 无人值守仍需补纸、补墨和处理硬件故障；异常时应停止接受新顾客并提示现场人员。
- 保留现有风格和用户界面成果。交付时说明具体部署版本，保留配置与配套数据库的回退备份。

[现场运行与部署](部署建议.md) 与 [Mac 安装说明](../README-Mac.md) 描述当前安装及运行方式。
