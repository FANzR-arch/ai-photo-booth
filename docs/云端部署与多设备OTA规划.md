# 云端部署与多设备 OTA 规划

更新：2026-10-13 · v1.0

**目标：把单机程序改成“云端主程序 + Windows 设备轻壳”，支持 100 台设备在同一城市铺开，所有设备可随时测试、灰度发版、批量更新和一键回退。**

## 已确定的条件

| 项目 | 决定 |
| --- | --- |
| 备案与云账号主体 | 甲方公司（域名、服务器、Seedream 账号、代码签名证书都用甲方公司实名） |
| 设备系统 | Windows |
| 规模 | 100 台，先在一个城市铺开 |
| 人脸告知 | 常规告知：拍照前屏幕提示 + 取图页隐私说明 |

现有 Mac 本地版继续用于当前 Demo 现场验收，云端版本不影响它。

## 总体架构

```
             云端（甲方公司账号，国内同城地域）
 ┌───────────────────────────────────────────────────┐
 │ booth.域名  正式环境      test.域名  测试环境       │
 │ · 拍照网页（所有界面）  · 生成服务（调 Seedream）     │
 │ · 模板 / 提示词         · 手机取图页（公网 HTTPS）   │
 │ · 总后台：设备 / 统计 / 发版 / 灰度 / 告警           │
 └──────────────────────────▲────────────────────────┘
                            │ HTTPS + 设备凭证
   ┌────────────┬───────────┴────────┬────────────┐
 设备 001     设备 002      ……       设备 100
 Windows 轻壳：全屏网页 · 摄像头 · 本地打印 · 自启 / 守护 · 自动更新
```

- **云端负责所有业务**：界面、模板、生成、取图、配置和统计。改一次，100 台设备都会生效。
- **设备只做云端做不了的事**：摄像头、打印机、开机全屏、断网提示。轻壳很少改动。
- **API 密钥只放在云端**，设备上不保存密钥。

## 云端

| 组成 | 选择 | 理由 |
| --- | --- | --- |
| 云厂商 | 火山引擎（与 Seedream 同一账号体系），地域选离城市最近的 | 账号、费用、备案都在一处 |
| 服务器 | 云服务器 4 核 8G 起步，系统盘 SSD | 生图在上游完成，服务器主要做图片处理；100 台设备够用，监控后再加配置 |
| 带宽 | 按流量计费 | 每单上传、取图、打印约 10–20MB，高峰流量波动大，按流量计费更合适 |
| 数据库 | 第一阶段继续用 SQLite（加设备、到期时间、取图凭证索引），每天自动备份到对象存储 | 单台服务器、100 台设备的写入量不大，改动最小；以后需要多台服务器时再迁移到云数据库 |
| 照片 | 第一阶段存在服务器磁盘，10 分钟后删除 | 10 分钟内的在途照片约 1–2GB；以后需要时换成对象存储 + 临时签名链接 |
| 域名与证书 | 一个主域名，`booth.` 正式、`test.` 测试、`admin.` 总后台；用云厂商的免费证书 | HTTPS 是摄像头权限的前提 |
| 进程管理 | 反向代理（Nginx 或 Caddy）+ systemd 守护；每次发版保留最近 5 个版本 | 支持一键回退 |

**Seedream 额度**：100 台设备高峰时可能有几十张同时生成。上线前要在火山方舟控制台确认甲方账号的每分钟出图数（IPM）和并发上限，不够就申请提高；总后台另外设置每台设备的每日上限和全局每日预算。

## 设备端：Windows 轻壳

用 Electron 做一个安装包。安装后：

| 功能 | 做法 |
| --- | --- |
| 全屏打开云端网页 | 隐藏系统界面和地址栏，顾客无法退出 |
| 设备激活 | 安装时运维人员接键盘，输入总后台生成的一次性激活码；之后自动携带设备凭证 |
| 开机自启、崩溃重启 | Windows 自动登录 + 开机启动；守护进程检测白屏或卡死后自动重启 |
| 断网 | 显示“设备维护中”，网络恢复后自动回到首页 |
| 本地打印 | 云端下发打印任务，轻壳下载成片后静默打印到本机打印机，并回报结果；沿用现有“同一张最多打印一次、结果不确定时不自动重打”的规则 |
| 距离提示 | 现在取景时每 0.9 秒把画面发给服务端做人脸检测，100 台设备会让服务器过载；改成在设备本机检测（项目已带 TensorFlow.js / face-api，浏览器里能直接运行） |
| 自身更新 | electron-updater，更新包放在云端，后台空闲时下载，下次重启生效 |
| 运维 | 每台设备装远程协助工具，加上一键配置脚本：关闭睡眠、设置 Windows 更新的活动时段（避免营业时间重启）、自动登录 |

建议以甲方公司名义购买 **Windows 代码签名证书**，避免安装和自动更新时被 SmartScreen 或杀毒软件拦截。

## 发版与批量更新（OTA）

1. **测试环境**：任何改动先发到 `test.`，用一台测试设备或电脑浏览器验证。
2. **正式发版**：服务器保留新旧两个版本的前端。每台设备在总后台属于“先行组”或“稳定组”，云端按分组决定加载哪个版本。
3. **空闲时更新**：设备每分钟检查一次版本，只在首页待机、没有进行中的拍照或生成时刷新。
4. **灰度**：先给先行组（3–5 台），观察 1–2 天，没问题再推给稳定组。
5. **一键回退**：总后台把分组切回上一个版本，设备空闲时自动回退。
6. **兼容要求**：新旧前端会同时在线，接口改动必须向后兼容至少一个版本。

## 云端改造清单

| 改动 | 现状（`apps/server/app.ts`） | 改成 |
| --- | --- | --- |
| 访问控制 | 只允许本机访问，手机取图除外 | 设备凭证认证；总后台用管理员账号登录；取图仍用一次性凭证 |
| 数据 | 整机共用 | 拍摄任务、打印任务和设备设置都带设备编号，设备之间互相看不到 |
| 并发 | 全局同时只能生成一张 | 每台设备一张，全局按 Seedream 上限排队 |
| 配置 | 本机工作台 | 模板 / 提示词 / 美颜等全局设置放总后台；摄像头、打印机、倒计时放设备设置 |
| 取图 | 局域网地址 + 店内 Wi-Fi | 公网 `https://booth.域名/pickup/…`，去掉 Wi-Fi 二维码 |
| 限额 | 无 | 每台设备每日上限、全局每日预算、接口频率限制 |
| 照片清理 | 每秒全表扫描 | 按到期时间建索引，只处理到期的记录 |
| 监控 | 无 | 设备心跳（在线、打印机状态、版本号、最近错误）；离线或连续失败时推送企业微信或钉钉告警 |
| 测试模式 | 整机开关 | 按设备开关，测试设备不消耗 Seedream 额度 |

现有的提示词、模板、等待页、相纸编辑和界面都继续沿用。

## 告知

- 拍照前在屏幕上显示一行告知：照片仅用于本次生成，上传至服务器处理，10 分钟后自动删除。
- 手机取图页底部放隐私说明链接，内容包括用途、保存期限、第三方处理方（火山引擎 Seedream）。
- 设备旁放一张同样内容的纸质告知。

具体文案由甲方确认。

## 时间安排

| 阶段 | 内容 | 预计 | 完成标志 |
| --- | --- | --- | --- |
| 0 · 准备（甲方） | 开通云账号，买域名和服务器，**立即提交备案** | 备案 1–3 周，与阶段 1 同时进行 | 备案通过，HTTPS 能访问 |
| 1 · 上云 | 设备认证、数据按设备隔离、公网取图、本机测距、限额、测试环境 | 1–2 周 | 一台 Windows 设备用浏览器完整跑通拍照、生成和手机取图 |
| 2 · 轻壳 | Electron 全屏、激活、Windows 打印、自启与守护、断网页、自动更新、一键配置脚本 | 1–2 周 | 试点设备无人值守跑满 3 天，打印正常 |
| 3 · 多设备 | 总后台：设备列表、在线状态、统计、分组灰度、回退、告警 | 1–2 周 | 5 台设备同时运行，灰度发版和回退都验证通过 |
| 4 · 铺开 | 每批 20–30 台，逐批安装激活 | 按装机节奏 | 100 台在线，每天数据正常 |

备案完成前，阶段 1 先在本地和测试服务器的 IP 地址上开发验证，不影响进度。

## 甲方需要准备

1. **备案材料**：营业执照、法人和网站负责人的身份证、负责人手机；备案时负责人需要配合人脸核验。
2. **账号**：甲方公司实名的火山引擎账号（服务器、Seedream 都在同一账号下），绑定付款方式。
3. **域名**：甲方公司实名购买，备案前不能对外解析使用。
4. **设备资料**：Windows 版本、摄像头型号、屏幕分辨率、**打印机型号和相纸尺寸**（Windows 打印要按这款驱动适配）。
5. **代码签名证书**：甲方公司名义购买（OV 即可）。
6. **告知文案**：按上面要点确认。
7. **运维联系人**：告警接收人（企业微信或钉钉群）和现场维护人员。

## 风险

- **单台服务器**：服务器故障时所有设备停用。用每日备份和快速重建脚本缩短恢复时间；以后单量增长再考虑多台服务器。
- **网络**：门店断网时设备暂停服务。现在生图本来就要联网，影响不变；建议门店网络稳定，必要时配 4G 备用路由。
- **Seedream 上限**：高峰时可能排队，等待页要显示排队状态；上线前确认额度。
- **Windows 打印**：照片打印机驱动差异大，要拿到实际型号后适配和实测。
