# 儿童主题扩充

2026-10-05

现场有不少小朋友客户，原有 63 个主题都是按成人设计的。这次新增 38 个儿童主题，分成两个新分类：**童趣奇遇**（23 个）和**小小职业**（15 个）。全部默认开启，主题总数从 63 个增加到 101 个。

## 选题思路

- **偏男孩的兴趣**：恐龙、太空、海盗、超人、骑士、机甲、赛车、消防车、挖掘机、侦探、足球、摇滚。
- **偏女孩的兴趣**：公主城堡、森林精灵、独角兽、冰雪城堡、糖果王国、芭蕾、甜品店。
- **不分男女**：海底、魔法学院、马戏团、露营、熊猫、科学家、医生、宠物医生、画家、机长、列车长、毕业照。
- **转绘玩法**：绘本主角、潮玩手办、蜡笔涂鸦、积木世界。
- **亲子同框**：亲子太空任务、超人一家、亲子烘焙屋，适合家长带孩子一起拍。

主题只决定场景和服装，系统不判断性别，也不会把主题限定给男孩或女孩。公主城堡、森林精灵和芭蕾这三个主题各写了女孩、男孩两套服装，生成时按本人的穿着气质自动选一套（例如男孩选“童话城堡”会穿王子礼服）。

## 写法约束

- 沿用现有的紧凑写法：每段主题提示词按“场景/光线 + 质感 + 动作：”来写，最长 89 字。拼装后的完整提示词不超过 520 字，测试会检查这一点。
- 用户选择“保留原服装”时，画面只换场景和道具；选择“按主题换装”时，才换上宇航服、公主裙等主题服装。
- **儿童头身比例**：成人模板要求“肩宽约为头宽的2到2.5倍”，套在孩子身上会显得年纪偏大。儿童主题改为“儿童保持本人年龄的稚气头身比例，不拉长身形、不显成熟；成人肩宽约为头宽的2到2.5倍”，亲子同框时也适用。其他 63 个主题的提示词完全不变。
- **IP 与标志**：全部使用原创设定，不提迪士尼、漫威、奥特曼、乐高等现有角色或品牌，制服、宇航服和球衣也不加真实机构标志。测试会检查这些名称有没有出现。
- **拍摄引导**：单人主题提示“请家长退到画面外”，否则陪拍的家长会被一起画进画面（模板按实际人数生成）。亲子主题提示大人可以蹲下或抱起孩子。

## 代码位置

- 提示词：`config/styles/styles.json`，ID 以 `kids-` 开头。已安装的设备重启服务后会自动导入，不会覆盖后台已经改过的主题。
- 分类、相框、拍摄引导：`packages/shared/kids-collection.ts`
- 儿童头身比例：`apps/server/generation-prompt.ts` 里的 `kidsProportion`
- 封面：`assets/examples/kids-*.webp`，共 41 张 720×960 的竖版 3:4 封面，来自 Codex 内置 imagegen 生成的虚构儿童原创示意图，**不是 Seedream 实测成片**。场景和服装取自对应主题的 `prompt` 与 `outfitPrompt`。童话城堡、森林小精灵和芭蕾各有女孩、男孩两版，主题页轮播显示。
- 原图、最终英文提示词与 SHA-256 校验清单：`docs/sources/kids-covers/manifest.json`；甲方总览图：`docs/sources/kids-covers/overview.png`；逐张目检与返工记录：`docs/sources/kids-covers/review-log.json`。
- 2026-10-05 后续反馈：潮玩手办封面单独改为无底座的完整站姿，露出双脚并调整脸部与身体比例；实际主题提示词同步去掉底座描述，旧默认提示词通过哈希迁移更新，后台自定义提示词保留。其余封面沿用前次版本。
- 已安装设备：`scene-quality-migration.json` 记录了 38 个旧 SVG 地址的 JSON 字符串哈希。服务重启时只替换仍使用旧默认封面的主题，并同步三个双版本主题的第二张图；后台人工换过的封面保留，开关、其他自定义字段和过去会话快照也保留。新安装直接使用 WebP。升级需要一并带上 `styles.json`、迁移清单、`app.ts` 和 41 张封面文件。
- 封面重建命令：`node scripts/save-kids-covers.mjs <id> <generated-png>`，会存档原图并按 150 KB 上限调整 WebP 压缩质量；总览图可用 `node scripts/save-kids-covers.mjs --overview` 重建。这两个命令只处理本地文件。

## 验证

- 本次封面交付的验收结果与文件体积见 `docs/sources/kids-covers/交付记录.md`；图像目检和自动化检查分别记录，目检不替代甲方的视觉确认。
- 全部 166 项测试通过，`tsc --noEmit` 与生产构建通过，包含儿童封面文件校验和双封面重启升级用例。
