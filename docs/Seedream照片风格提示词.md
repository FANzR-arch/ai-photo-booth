# Seedream 照片风格提示词 · V2 草案

适用项目：咔嚓！SNAP CLUB 线下 AI 拍照亭。输入一张清晰单人人像，用户选择风格，后台提交一段完整提示词，输出一张本人风格照。模型：`doubao-seedream-5-0-pro-260628`。

## 依据与使用边界

- 当前项目 `config/styles/styles.json` 已启用三类：电影主角 `cinema`、职场高光 `business`、另一个次元 `cartoon`。本稿沿用其视觉方向，精简和明确生成要求。
- 原始产品计划另含时尚杂志、二次元、复古胶片、城市限定、节日限定、IP／品牌联名，共九类。本稿全部覆盖；新增六类只是内容候选，不代表已上线。
- 官方来源：[Seedream 提示词指南](https://ark.volcengine.com/region:cn-beijing/docs/82379/1829186?lang=zh)、[图片生成接口](https://www.volcengine.com/docs/82379/1541523)。2026-09-16 已阅读用户补充的指南全文，本地原文留存在 `sources/Seedream官方提示词指南-用户提供-2026-09-16.txt`。
- 指南正文明确适用 Seedream 5.0 lite、4.5、4.0；本稿将其通用写作方法应用于当前 5.0 pro，是项目采用的迁移方法，不把该文当作 pro 专属能力说明。pro 的单图和参数限制按此前接口正文及项目实测配置处理。
- 用户此前提供的官方接口正文另建议中文提示词不超过 300 字，支持在提示词中描述宽高比，参考图片经 `image` 参数传入。以下每段控制在 300 个字符以内，比仅计算汉字更严格。
- 以下提示词是按官方方法为本项目原创编写，并非官方示例。构图和审美取舍是项目建议；先前橘猫文生图只验证了接口可用，尚未验证这里的人像保真或九类成片效果。

### 官方方法如何落实

| 官方指南建议 | 本稿处理 |
|---|---|
| 简洁连贯的“主体 + 行为 + 环境” | 明确参考照片中的人物，说明站在街边、坐在窗边或置于棚拍背景，而非堆叠零散关键词 |
| 写清应用场景和用途 | 开头直接说明电影剧照、商务肖像、杂志内页、城市纪念照等成片类型 |
| 使用精准风格词或风格参考图 | 区分胶片颗粒、赛璐璐阴影、哑光3D材质；当前无风格图输入，不虚构第二张参考图 |
| 明确编辑对象、操作和不变部分 | 写明换穿外套、替换背景；保留人物五官、年龄感、发型、眼镜和表情 |
| 参考图生成明确“参考对象 + 生成画面” | 参考本人形象，重新描述环境、光线、构图；不要求整张原图保持不变 |
| 图片中的指定文字用双引号 | 当前成片无字；若后续生成文字，应写成“标题为 \"指定文字\"”；精确品牌排版优先后期处理 |
| 多图输入明确每张图的职责 | 当前只有一张人像，不使用“参考图二”等无来源指令；联名合影需另行扩展 |

不使用本指南中的“一套／一系列／生成四张图”等组图指令，因为当前项目使用 5.0 pro 单图调用。

## 怎么写、怎么接

采用自然语言完整描述：**编辑目标 → 保留的人物特征 → 服装与场景 → 构图与光线 → 必要限制**。一段只表达一个明确视觉方向，避免堆砌“顶级、8K、杰作”等空泛词。

以下代码块均是完整 `prompt`，直接选择其中一段使用，不要再拼接重复的通用前缀。当前适配器使用 `image + prompt`，没有独立系统消息或负面提示词字段；后台所谓“系统提示词”实际应填入 `prompt`。

通用输入建议：单人、面部清晰、无遮挡、均匀曝光，取景至少包含完整头部与肩部。原照如果缺失额头或肩部，文字无法可靠恢复。保持肤色、年龄特征、发型和眼镜，不以统一瘦脸、美白、幼化制造“好看”。写实风格保留皮肤纹理；卡通风格保留身份特征而允许材质变化。

构图默认统一竖幅 3:4、胸部以上肖像，头顶留白、肩部完整，手在画外。便于自拍输入、设备预览和手机收藏，也降低重建手部与全身姿态的难度。这是本项目取舍；若未来改成双人或全身照，应另写对应模板。

## 一、现有三类：可直接用于后台

### 01 电影主角 · 雨夜霓虹

- ID：`cinema`；沿用现有紫蓝霓虹与琥珀轮廓光方向。
- 卡片文案：雨夜霓虹，你就是这一幕的主角。
- 看点：电影感来自场景和光色，脸部仍清晰自然。

```text
将参考照片中的人物制作成一张雨夜都市电影剧照。保留本人的脸型、五官比例、肤色、年龄特征、发型和眼镜，保持原照的表情与头部朝向。人物换穿合体深色外套，站在雨后街边，远处紫蓝霓虹与路面反光虚化，暖琥珀色轮廓光勾勒肩线，柔和主光照清面部。竖幅3:4，胸部以上肖像，头顶留白、双肩完整、手在画外。真实皮肤纹理，克制的胶片颗粒，暗部保留细节。仅一位人物，无文字、片名、边框或标志。
```

## 三、尺寸、数量与实际配置

- 沿用当前 `size: "1.5K"`，提示词描述竖幅 3:4；自然语言不能保证精确像素比。
- 若产品必须固定 3:4，可使用 `size: "1296x1728"`。总像素 2,239,488，宽高比 0.75，符合用户提供的 5.0 pro 接口范围；这是参数推导，尚未实测该尺寸。
- 5.0 pro 每次返回单图，不传 `sequential_image_generation`。需要两张时是两次独立调用。不要在同一 prompt 中要求拼成两张、四宫格或同时呈现不同风格。
- 当前代码对多张请求复用同一个 prompt；本稿不声称已实现姿态或镜头变体。如果未来要稳定提供两种构图，应显式加入逐张变体逻辑。
- 原图 `watermark: false` 与付费前预览水印是两层逻辑；预览水印应由项目后端加在预览文件上，无需写进生成 prompt。
- 本稿未替换 `config/styles/styles.json`，未改数据库。可配合 `Seedream照片风格提示词.json` 手动复制到后台。运行中风格以 SQLite 为准，单改初始 JSON 不会覆盖已有风格。

## 四、最小样片验收

先用同一张已获授权的人像验证商务、电影、3D 三类，每次一张；本稿交付不包含付费调用。

1. **是不是本人**：比较脸型、眉眼位置、鼻口比例、年龄感、眼镜与发型。失败先减弱风格化，不追加空泛“更像本人”。
2. **类型是否鲜明**：电影是夜景光色、商务是自然棚拍、3D 是明确立体材质；不接受只有背景颜色变了。
3. **面部是否可用**：眼睛清晰，曝光自然，无明显磨皮、漂白、五官遮挡或形变。
4. **交付构图**：单人、完整头部肩部、足够留白；无多余文字、拼图及道具穿插。
5. **版本记录**：记录模型、完整 prompt、size、输入样本、耗时和用户评价。满意后再扩展样本与启用新风格；单张成功不等于对所有人稳定。

修正时一次只动一个问题：脸太暗就调主光；卡通不像本人就降低眼睛放大程度；背景抢人就减少道具和清晰度。不要同时改人物、场景、镜头、光线，否则无法判断哪项改变有效。
