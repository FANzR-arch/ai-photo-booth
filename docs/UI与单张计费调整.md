# UI 与单张计费调整

2026-09-16

- 拍照亭每次生成一张效果图；原照片免费，结果页独立展示并提供下载入口，原图不会加入购买订单。
- 后端订单只接受一个有效生成图 ID，金额 990 分；旧会话中的多个生成结果可单选购买，不把旧演示效果误标成原图。
- 原图接口 `/api/sessions/:id/original` 仅本机访问，无需付款，禁止缓存。会话结束或过期后不可再取；已购照片继续走原有 token 取图流程。手机端仍通过付费相册下载已购生成图，免费原图入口当前用于本机保存。
- 品牌采用官方 [Lucide Camera](https://lucide.dev/icons/camera)，获取来源为 Lucide GitHub 主仓库，ISC 许可证保留于 `assets/licenses/LUCIDE-LICENSE.txt`。内联 SVG 随页面加载，手机取图页无需额外访问受限素材接口。
- 整体采用暖白纸色、朱红主按钮、低饱和绿提示；调整首页画面圆角、标题字体、步骤状态、主题卡片、拍摄确认、结果对比和支付票据。原有 21 种主题与原图等待动画保留。

## 验证

2026-09-17 转场补充：主题卡片从外侧错峰飞入；其他页面采用短淡出接轻微上浮，导航固定，确认、生成和结果页之间保留照片位置衔接。结束体验立即清除照片；不支持 View Transition 的浏览器使用入场动画，系统开启“减少动态效果”时取消转场。构建和 46 项测试通过，覆盖连续切换、结束时取消旧转场、减少动态效果，以及主题重新加载后重播入场。最新动效因浏览器工具连接异常尚未完成现场观感复核。

- 构建通过，42 项测试通过。覆盖默认单张、990 分订单、免费原图读取、原图不可购买、远程读取拒绝、结束会话后失效及既有拍照／取图回归。
- 浏览器实际完成：示例照片 → 同意本机处理 → 一张演示结果 → 模拟购买 1 张 ¥9.90 → 单张订单 → 模拟支付成功 → 取图二维码。
- 实际检查首页、1501×1272 结果页和 390×844 手机宽度结果页，无横向溢出，原图与生成图标签及收费入口可区分。系统默认浏览器尺寸已恢复。
- 未实测摄像头、真实付费 API 或手机扫码下载；未重新打包 Windows 压缩包。预览在独立 demo 实例运行，旧端口实例仍沿用启动时的后端规则，应使用新版预览或重启源码服务。
