# 等待体验 · 第一步：调研

2026-10-13。在 [等待小游戏调研.md](等待小游戏调研.md) 的基础上放开范围：不只看“小游戏”，而是看等待时人可以做的所有事，以及等待本身的心理。本文只做调研，不做选型（选型在第二步）。

## 〇、现在的等待页是什么样

- 左边：顾客原照片，上面有一道扫光，角标“重绘中”，下方“已等待 N 秒”，40 秒后加一行“仍在处理中…”；
- 右边：“AI 正在绘制你的照片 / 通常 30–60 秒，画好会自动跳转”，下面是戳泡泡；
- 照片好了直接跳结果页，泡泡游戏随之消失。

已经做对的：显示原照片（安心）、给了预期区间、用“已等待”而不是倒计时（见下文 2026 年 CHI 研究）。
还缺的：等待的**开头**和**结尾**都没有设计；泡泡 30 秒后单调；照片好的那一刻没有“揭晓”；超过 60 秒以后没有新的东西。

## 一、等待心理：什么让人觉得久，什么让人觉得快

### 1. 经典规律（Maister 1985 及 Norman 的补充）

| 规律 | 放到拍照机上 |
|---|---|
| 闲着的时间比有事做的时间显得长 | 要给手和眼睛一点事做 |
| 开始前的等待比过程中的等待显得长 | 顾客点了“开始生成”就算进入过程，要让人**感到已经开始**，第一秒就要有动静 |
| 焦虑让等待显得更长 | 第一次用、刚付了钱：“到底成功没？钱白花了吗？”是最大的焦虑源 |
| 不确定的等待比已知的长 | 给一个区间，并让人看到“在往前走” |
| 没解释的等待比有解释的长 | 告诉顾客 AI 在干什么 |
| 一个人等比一群人等显得长 | 情侣、亲子、闺蜜常是两三个人一起来，可以一起玩 |
| 越看重结果，越愿意等 | 照片是顾客自己的脸，本身就有很强的期待，这是可以利用的 |
| 人记住的是峰值和结尾（峰终定律） | 等待的结尾 = 照片揭晓，应该是整个流程的高潮 |

### 2. 近几年的研究，更贴近我们

| 研究 | 结论 | 对我们的意义 |
|---|---|---|
| **Van Nimwegen 等 2023**（n=410，手机网页） | 三种等待：只有进度条 / 看文字 / **用手划开一层像刮刮卡**。“划开”组觉得时间最短、也最开心 | “刮开/擦开”这种主动动作对缩短体感很有效，而且天然适合做“揭晓” |
| **Böddeker 等 2025**（服务业实验） | **主动**占用（自己动手做事）比被动占用（看电视）更容易进入心流，满意度和回头率更高；**但实际等待越长，这个好处越弱** | 游戏能帮忙，但不能指望一个游戏撑满 90 秒以上；慢的时候要有第二套内容 |
| **Caruelle 等 2023**（零售） | 比预期**短**，满意度大幅上升；比预期**长**，只是小幅下降（除非长很多） | 预期说得稍保守一点更划算：说“约 1 分钟”，40 秒出图就是惊喜 |
| **CHI 2026**《Counting the Wait》（n=425，10/30/60 秒等待） | **倒计时**比“已等待”更让人烦躁；**不显示时间**让等待显得更长、更迷茫 | 保持现在的“已等待 N 秒”，不要改成倒计时，更不要伪造百分比 |
| **Buell & Norton 2011**“劳动错觉” | 网站展示“我正在为你努力”（比如“正在比对 120 家航空公司”），人们甚至更喜欢慢一点但看得见过程的那个 | 让顾客“看见 AI 在画”：分阶段的过程描述、画面在逐渐变化，会提升对成片的价值感 |
| **CHI 2025**《While We Wait》（AI 生图用户访谈） | 研究进度条、骨架屏、文字描述这类“生成提示”对体验的影响 | AI 生图等待是一个新的、被专门研究的问题；目前主流做法就是“告诉你在干什么 + 给个时间感” |
| Harrison 2007/2010 进度条 | 前慢后快、带反向流动纹理的进度条感觉更快 | 如果做进度光带，用这个技巧 |

### 3. 一个很直接的反面案例：被打断的游戏

日本可用性博客“使いやすさ日記”记录过一台打印照片的自助机（PrintRush）：打印时屏幕上出现**翻牌配对**小游戏。作者玩得正投入、差一点就配完，打印完成，**画面直接切走**，游戏强制结束。作者的原话大意是：为了提升满意度而设计的游戏，最后反而让人失望。他的建议是：通知“打印好了”，但让最后一局玩完再切换，反正一局只有十几秒。

> 这正是我们现在的做法（照片一好立刻跳走）。第三步设计“收尾”时必须解决。

## 二、各领域的等待互动：类型和好例子

### A. 游戏读盘画面

| 例子 | 做法 | 可借鉴的点 |
|---|---|---|
| Namco《山脊赛车》（1994） | 读盘时玩一局《小蜜蜂》，Namco 为此申请专利，其他厂商因此 20 年不敢做，2015 年专利到期 | 读盘小游戏是被证明有效的老办法 |
| 《猎天使魔女》 | 读盘时可以自由练习连招 | 等待时练的就是主游戏的核心动作 |
| 《刺客信条》 | 读盘时在一片白色空间里自由奔跑 | 没有目标、没有失败，只是“让手有事做” |
| FIFA 系列 | 读盘时在训练场射门 | 同上，而且可以随时被打断 |
| 《质量效应》《银河战士》 | 用乘电梯、开门这样的过场掩盖读盘 | 等待被包装成故事的一部分，而不是“技术上在加载” |
| 《英雄联盟》《王者荣耀》 | 读盘画面展示双方英雄皮肤和每个玩家的加载进度 | 展示“马上要看到的东西”+ 看得见的进度 |
| 《造梦西游 3》、《方舟》手游 | 加载界面里有小游戏，B 站至今有人投稿“加载小游戏刷到 22 万分” | 国内玩家对“加载小游戏”有怀旧好感 |
| Chrome 断网小恐龙 | 一个跳、一个蹲，就能玩；鼎盛时每月 2.7 亿局 | 极简操作、零说明，也说明“等的时候顺手玩”是真实需求 |

### B. 主题乐园排队

| 例子 | 做法 | 可借鉴的点 |
|---|---|---|
| 迪士尼“七个小矮人矿车” | 排队区有多人触屏：把宝石按颜色分拣、在水槽里“洗宝石” | **多人同时摸一块屏**；动作简单；和后面的项目同一个故事 |
| 迪士尼“小熊维尼” | 排队墙上可以摸、可以戳的蜂蜜墙 | 没有规则，小孩自己会去摸 |
| 迪士尼“小飞侠” | 排队时墙上投影的小叮当会追着人影跑 | 屏幕“回应你”本身就有趣 |
| 迪士尼“鬼屋” | 排队区有可以弹奏的乐器墓碑、会说话的墓碑 | 让人提前进入主题氛围 |

规律：排队互动都在**为后面的体验定调**，而且鼓励一家人一起玩。

### C. 线下拍照机、大头贴机、照片打印机

| 例子 | 做法 | 可借鉴的点 |
|---|---|---|
| 日本大头贴机（プリクラ） | 拍完不是干等，而是走进隔壁的“涂鸦间”，在限定时间里给自己的照片加字、贴纸、画画，同时下一组在拍 | **把处理时间变成“装饰自己照片”的时间**；顾客觉得是在创作，而不是在等 |
| 日本大头贴机 | 涂鸦时有倒计时，结束后打印约一分钟，期间屏幕引导把照片传到手机 | 等待时间里顺手完成“取图”这件事 |
| PrintRush 照片打印机 | 打印时玩翻牌配对 | 有正面（好玩），也有反面（被强制打断，见上） |
| 开源项目 ICLBooth（美国一所大学的活动拍照机） | 首页有一个小游戏方块，**不碰时自己演示着玩**，一碰就开始；两分钟没人碰自动回首页 | **自动演示**比文字说明更好懂，也能吸引人去碰 |
| GitHub 上其他开源拍照机（pibooth、PhotoboothProject、photobooth-app、momentobooth 等） | 处理时基本只是转圈或倒计时 | 等待体验在同类产品里很少被认真做，是可以拉开差距的地方 |
| 国内自助照相馆 | 常见槽点是“拍完要等修图”“前后环节互相等” | 等待是这个行业的普遍痛点 |

### D. 解压、手感类（B 站 / 小红书热门方向）

- B 站“解压”内容播放量很高：捏冰块、捏泡泡、挤海绵这类视频动辄几十万到上百万播放；清洁类解压小游戏合集也很多。
- 共同点：**动作很小、反馈很大、结果可预期**（一捏就破、一擦就干净）。不需要输赢。
- 对应到触屏：戳破、擦干净、刮开、捏扁、撕开、点亮。
- 开源参考：`cheeaun/bubble-wrap`（网页戳泡泡纸）、`samccone/fidgetspin.xyz`（网页指尖陀螺）。

### E. 让人“看见在做事”（劳动错觉）

| 例子 | 做法 |
|---|---|
| 达美乐披萨进度条 | 下单后分阶段显示“备料、烤制、质检、出发” |
| 机票比价网站 | “正在搜索 XX 航空……”逐条滚动 |
| 外卖、网约车 | 地图上看骑手、车辆在移动 |
| Midjourney 等生图工具 | 画面从模糊逐步变清晰 |

注意：Seedream 不会给中间图，所以“逐步变清晰”只能用别的画面表达（比如原照片上的笔触动画、阶段文字），不能假装是真实的中间结果。

### F. 其他值得注意的类型

- **抽签、运势**：日本大头贴机和不少中国景区、奶茶店都有“抽一支签”。好处是一点就出结果、和拍照的仪式感相合；缺点是要识字。
- **有用的等待**：把本来要在后面做的事挪到等待里（大头贴机传手机、选相框、选相纸）。顾客既有事做，结果页之后的步骤也少了。
- **收集**：玩的过程中收集一个小贴纸、小印章，最后能印在照片边上。让游戏和成片产生关系。
- **体感**：用摄像头识别动作。好玩，但要重新开摄像头、涉及隐私，开发量大。

## 三、我们的场景特点（做方案时要守住的）

1. **只用一次、多数第一次用**：没有学习曲线可言，看一眼就要会；最好不靠文字，会自己演示。
2. **从小孩到老人**：只用“点”最稳；拖动、精准时机对老人小孩都难；目标要大。
3. **刚付了钱**：焦虑主要来自“成功了吗”。游戏之外，必须一直让人看到照片在处理。
4. **常常两三人一起**：值得支持两人同时玩（要真机确认多点触控）。
5. **等待时长不固定**：通常 30–60 秒，偶尔更长，偶尔失败。主动玩法在长等待里效果会变弱，需要分阶段。
6. **随时可能被打断**：照片好了，游戏要能体面地收尾，不能“差一点就通关”时被切走。
7. **没有声音**（暂时）：节奏类、听声类不考虑。
8. **隐私**：不重新开摄像头，不要输入文字。用顾客原照片做游戏素材是否可以，需要你来定（之前的调研写的是不用）。

## 四、我从调研里得出的几个判断

1. **等待体验 ≠ 小游戏。** 最好的例子（大头贴涂鸦间、迪士尼排队、读盘练招）都是“和主体验有关的事”。游戏只是其中一块，另外两块是**看见过程**和**揭晓时刻**。
2. **开头、中间、结尾要分开设计。** 开头要立刻给“已经开始了”的确定感；中间给手头的事；结尾是整段流程的高潮，现在恰恰是最弱的。
3. **“刮开 / 擦开”是一个很少见的好东西**：研究证明它能缩短体感，又天然就是揭晓动作，可以把“等待的玩法”和“看成片”连成一件事。
4. **不要被打断。** 照片好了先提示，让顾客自己结束这一局，或者游戏本身没有“一局”的概念。
5. **长等待要有备用内容。** 60 秒后换一个新东西（新玩法、新提示、新阶段），比一个游戏玩到底好。
6. **预期稍保守**，并继续用“已等待”而不是倒计时。
