## 2026-10-05 头身比例、参考图自动构图与美颜强度

- 背景：甲方反馈成片像“大头娃娃”。原因是顾客贴近广角摄像头拍摄，原片头大肩窄；提示词把“人脸一致性”放在最高优先级，模型照搬了被透视放大的头，再补一个偏瘦的身体。另查到 Seedream 官方建议提示词不超过 300 个汉字，当前每条约 2600 字，细节会被忽略。
- 拍照页：引导语改为“离摄像头约一米，让头顶到腰部都在画面里”，不再要求靠近。透视畸变由距离决定，靠近只会放大头部。
- 提示词：每条提示词第一行新增【头身比例】锚点（成年人头身比约 1:7 到 1:7.5、肩宽约头宽 2 到 2.5 倍、85mm 人像透视、不照搬原照近距离透视），优先级改为“人脸身份 > 头身比例与肢体结构 > 表情/服装/画幅 > 主题”。职场高光动作从“双臂交叉于胸前”改为“双手轻置腰前或一手轻搭另一侧手肘”，旧提示词哈希已登记到 `scene-quality-migration.json`，已安装设备重启后自动升级，自定义内容保留。
- 参考图自动构图：`apps/server/reference-framing.ts` 在本机用 tiny face detector（tfjs wasm 后端，单张约 50 毫秒，模型随 npm 包内置、不联网）检测人脸；脸高占画面 14% 到 22% 之外时，按输出画幅把照片扩边（或裁切）到脸高约 18%，扩边区域为取自照片的纯色。检测不到人脸或失败时按原图生成。每次会话写入 `data/sessions/<id>/reference.json`，扩边后的参考图另存为 `reference.jpg`。
- 美颜强度：工作台新增「人像处理」面板，美颜强度关闭 / 轻度 / 中度，默认轻度；参考照片自动构图默认开启。接口 `GET/PUT /api/admin/portrait`。美颜文案插在【表情幅度】之后，仍要求保持脸型、五官位置与年龄感。
- 真实对照（`docs/evidence/portrait-proportion-2026-10-05/`，职场高光 3:4，同一张近距离自拍）：旧提示词+原图 → 脸高占画面 25.6%、脸宽占 36.0%，肩窄头大；新提示词+扩边+轻美颜 → 27.6% / 37.0%，肩膀明显变宽；精简提示词（256 字）+扩边+轻美颜 → 26.1% / 35.2%，肩宽最自然、动作执行最准。三者各一张样本，头部占画面比例差别不大，模型仍主要自行决定取景；改善主要来自肩膀与躯干变宽。`comparison.jpg` 为并排对比图，`scripts/test-portrait.ts` 可复现（`--live --source --run --style --tag [--reframe] [--beauty] [--prompt-file]`）。
- 结论与待办：精简提示词是最有潜力的方向，但需要重写 63 款模板与对应测试，本次未改；建议下一步按“人物｜场景｜光线｜构图”四段、300 字以内重写并逐款实测。
- 新增依赖：`@vladmandic/face-api`、`@tensorflow/tfjs`、`@tensorflow/tfjs-backend-wasm`。构建通过，163 / 163 项测试通过（含新增 6 项；两项生成去重测试改为等待上游调用发生后再断言）。工作台新面板未在浏览器实查。
