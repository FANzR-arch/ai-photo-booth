# 当前 Demo 进度

更新：2026-09-16。定位：可在 Windows 本机运行的线下触屏拍照亭内部演示版。

## 已完成

| 模块 | 当前能力 |
|---|---|
| 待机与主题 | 广告轮播、全屏入口、纵向滑动图库、统一 3:4 封面；七个主题共 28 张角色参考 |
| 触屏交互 | 大按钮、按压反馈、淡入轮播、暂停、减少动态效果支持 |
| 照片输入 | 浏览器摄像头、倒计时、重拍、JPG/PNG 上传；12–60 MB 大图自动缩小，不修改原件 |
| AI 生成 | 服务端真实 Seedream 图生图、进度轮询、刷新恢复、重复提交保护、部分失败与未知状态处理 |
| 交易交付 | 选图、模拟订单、单张解锁、二维码、局域网下载、取图凭证与到期清理 |
| 管理 | 风格开关、提示词与版本、示例图配置、任务记录；仅本机访问 |

九套主题配置中七套启用，城市与品牌主题待填写实际内容后启用。参考图库是 AI 创作的方向素材，不构成对实际生成效果的承诺。

## 已验证

- TypeScript/Vite 构建通过，36 项自动测试通过。
- 浏览器查看横竖屏图库、轮播暂停、上传、生成结果、模拟购买和取图二维码。
- 使用用户授权的人像原片实际测试：约 30 MB 原片处理上传，电影主题 Seedream 图生图耗时 35.326 秒，产出 1248×1872 图片。
- 对该生成结果完成模拟解锁，电脑通过局域网地址下载返回 200；错误凭证返回 404，局域网管理请求返回 403。
- 修复受限进程联网失败的提示，并在允许联网的服务进程中完成真实生成。

个人照片、下载结果及包含本机会话标识的原始测试证据仅在本地保存，不包含在仓库里。上述是已完成的开发验收摘要。
