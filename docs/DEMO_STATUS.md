- 正式启动使用固定端口和持久化 data；不再每次启动新建数据库。与已有服务模式不同会明确拒绝复用。
- 模拟生图入口使用独立临时实例，避免误把本地处理结果当作真实 AI 效果。

- 电影主角、旧日来信、节日限定各只在一个用途分类出现。当前 52 款启用、2 款待配置模板。
- 按最新要求，首页、结果页、付款页和工作台使用正式购买文案；底层仍保留模拟支付，新订单带 paymentMode=simulate。

- 新版打包脚本只复制空白配置，不再附带本机密钥；当前未重新制作 ZIP。
- 各拍摄步骤增加返回，本轮照片库支持多张照片找回、已购取图码重开；结束体验清空本轮入口，不向下一位用户展示。

- 确认照片增加“保留原服装 / 按主题换装”，默认保留。53 款普通模板分别设置换装搭配，保留身份、体型与人数；动作由主题设计。工作台可独立编辑换装搭配，自定义提示词不被升级覆盖。
- 53 款模板增加质量要求：37 款写实主题覆盖合照景深、自然皮肤、曝光层次、衣料与光影衔接；16 款艺术主题分别保留像素网格、笔触和手作材质。移除固定竖版、胸部以上和手在画外的要求，按所选画幅与主题动作重新安排构图。输出尺寸仍为 1.5K，未调整模型或新增调用。
- 新增「你好，我的18岁」：位于“留下今天”首位，单独执行用户提供的成人礼海报提示词；固定 2:3、深蓝换装、允许整理发型和重设姿势，文字直接生成在图内。公共封面为排版示意，未使用用户上传的人像。
- 人脸一致性改为最高优先级：动作、手势、视线、表情、头部朝向与站位可按提示词设计。清理 53 款普通模板及 3 处换装提示词中的原姿势约束；衣服是否更换不再限制动作。成人礼完整提示词保持原样，旧成片及自定义编辑保留。
