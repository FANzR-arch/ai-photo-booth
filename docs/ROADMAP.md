# 后续发展计划

以下为建议推进顺序，不代表已完成或已确定上线日期。

## 1. 同事可直接演示（演示包已完成，待现场验收）

- 已制作 Windows 演示包：内置运行环境与构建产物，双击启动并打开浏览器。
- 首次配置密钥，检查网络、摄像头、端口及手机取图地址。
- 完成至少一台同事电脑和一部手机的拍摄、生成、模拟解锁、保存验收。
- 测试网络断开、摄像头占用、重复点击、重启与连续使用。

交付目标：无需开发环境即可顺畅演示；无需域名和云服务器。

## 2. 门店试用

- 依据实际触屏尺寸、相机型号、补光和站位优化取景与布局。
- 为主题建立真人效果样本，重点检查相似度、眼镜、年龄和失败比例。
- 增加设备登录、管理员保护、调用预算、每日上限、诊断日志。
- 提供开机启动、断网提示、磁盘空间检查及明确的数据清理策略。

交付目标：可控成本的小范围门店试用。

## 3. 真实支付与交付

- 由门店商户接入微信支付等渠道，以服务端验签回调确认付款并解锁。
- 完善订单对账、重复回调处理、超时取消和退款流程。
- 如果需要离店后取图，增加 HTTPS 公网取图服务、私有对象存储和有效期控制。

交付目标：实际支付状态与下载权限一致，用户能可靠拿到已购照片。

## 4. 多门店与云端

- 统一管理设备、主题、模型配置、额度和运行情况。
- 将本地 SQLite/磁盘交付迁移或同步至云端数据库、存储和任务服务。
- 前端可选择 Vercel；当前常驻后端、本地数据库及磁盘照片不能直接按静态网站方式上传后继续工作。
- 按真实需求再决定打印、专用相机和桌面封装，避免 Demo 阶段过早增加维护成本。
