# 现场运行与部署

本文记录 2026-09-29 的 Windows 现场运行版本。Mac 安装见 [Mac 安装说明](../README-Mac.md)；无人值守的剩余工作见 [无人值守上线](无人值守上线.md)。当前代码为 **真实 Seedream 生图、程序内无付款环节**（现场先收费再使用），没有公网发布。

## 固定设备启动

- 源码：Node.js 24+，双击 `启动拍照亭.cmd` 或 `start-photo-booth.cmd`。首次安装使用 package-lock.json 锁定版本。
- 便携包：自带 Node 和构建文件；填写本机 .env 后双击启动。新包不会附带任何真实密钥。
- 命令行：`npm ci` → `npm run build` → `npm start`。
- 默认使用 localhost:4377，真实模式缺少密钥、模型或构建文件会停止启动，不会回退模拟生图。
- 真实模式必须使用固定端口及 data 数据库，禁止 BOOTH_FRESH_INSTANCE=1。重复启动只打开相同模式的已有服务，不会重置运行中的任务。
- 停止服务用启动窗口的 Ctrl+C，等待任务结束。强制终止后，未确认的云端生成会标记为“结果未知”，不自动重试。

保持电脑供电、联网，并关闭运行期间的自动睡眠。自动开机运行、系统更新与门店设备策略应在目标设备设置并验收。

## 手机取图

电脑用 localhost 打开拍照亭；手机需连接同一 Wi-Fi。后端自动选择本机 IPv4 地址，也可以在 .env 中固定 PICKUP_BASE_URL，例如 http://192.168.1.20:4377。

建议为设备保留固定局域网地址，避免换网或 DHCP 地址变化导致旧二维码失效。电脑、防火墙及路由器须允许手机访问对应端口；程序不自动修改系统防火墙。管理与拍照接口仍然只对本机开放。

新照片从生成完成起保存 10 分钟；未完成生成的拍摄任务自创建起最多保留 10 分钟。查看、下载和重启不延长有效期。升级前的照片沿用原先的到期时间。

到期立即拒绝读取；运行中的清理任务每秒检查并删除原照片、生成图、预览图、相纸文字和取图凭证，保留到期状态记录。停机期间到期的照片会在下次启动时清理。照片库和手机取图页同时收起到期图片；已下载到用户手机的文件不受影响。本机清理不控制云端供应商的数据保留。

照片库只收录当前一轮已知的拍摄任务，不提供全设备照片列表。返回和“再拍一张”保留本轮照片；“结束本次”结束本轮全部任务并清空浏览器记录。无操作 2 分钟自动结束，生成任务进行时为 5 分钟；刷新时也检查是否超时。尚未提交的原照片只在内存中，刷新后需重新拍摄或上传。

已完成体验的取图链接在有效期内仍能使用。重启保持原端口、数据目录和局域网地址时，原链接继续有效。

## 数据与更新

1. 停止拍照并等待正在生成的任务完成，用 Ctrl+C 正常退出服务。
2. 将 data 目录、.env 和当前程序保存在有访问限制的备份位置；照片属于顾客数据，按同一保留策略管理备份。
3. 更新源码和构建，保留原 data 与 .env，再启动。
4. 打开工作台检查模式和模板；需要回退时停止服务并恢复配套程序与备份。

本次模板升级将重复的 natural（自然的你）移出活动模板库，保留 business（职场高光）。旧条目及自定义提示词归档在同一数据库的 retired-style 中，旧会话仍可完成；不会清空会话或其他手动设置。电影主角、旧日来信、节日限定各只保留一个分类入口。最终为 51 款启用模板、2 款待配置模板。

## 收费与上线边界

程序内不设付款环节：顾客在现场先付费，再使用拍照亭。确认照片后直接生成，结果页可打印，手机取图包含 AI 成片与拍摄原片。自动打印仍需后续接入，最新安排见 [甲方需求对照与更新规划](甲方需求对照与更新规划.md)。

真实生图仍会消耗 Seedream 账户额度；本次改造没有新增付费生图测试。每台服务只允许一个正在进行的生成任务；这不等于每日预算上限。

公开网站还需另行设计身份认证、限额、HTTPS、持久化服务和私有照片存储。当前 Node + SQLite 常驻任务服务不能只上传前端到 Vercel 就完成公开部署。

当前自动化和浏览器验证范围见 DEMO_STATUS.md。摄像头硬件、实体手机扫码保存、长时间连续运行及各模板的人像相似度仍需目标设备验收。
