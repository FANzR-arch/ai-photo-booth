# 部署建议与本次真实照片验收

## 当前可用范围

2026-09-16 使用用户指定的 DSC06281.jpg（约 30 MB，6336×8448）在浏览器上传，前端将大图缩至最长边 2048 后提交，原始文件未修改。电影主题真实 Seedream 图生图耗时 35.326 秒，返回 1248×1872 图片。浏览器完成预览、单张 9.90 元模拟订单与解锁二维码；本机通过 LAN 地址下载原图 HTTP 200，错误凭证 404，LAN 管理入口 403。证据见 evidence/real-photo-test.json。

首次请求在受限进程内遇到 connect EACCES；检查不带密钥的官方接口连通性后，切换到允许联网的本地服务进程完成测试。该错误现在区分为请求未发出的已知失败；响应后的失败和不明确网络中断仍禁止自动重试。旧未知记录保留，没有伪造成功状态。

本次用照片代替摄像头，因此不能证明摄像头硬件通过验收。LAN 下载是在电脑上验证，不能代替物理手机扫码保存。真实支付、其他主题本人相似度、门店长时间运行尚未验收。

## 是否部署 Vercel

前端静态页面可以部署到 Vercel，但现有整套项目不能直接作为完整线上拍照亭发布：

- Fastify 是常驻服务，生成请求返回后，后台任务继续运行并接受页面轮询。
- SQLite 数据库和照片在本机磁盘保存，需要持久化存储。
- 拍照和管理接口只允许 localhost；二维码当前指向电脑局域网地址。
- 前端使用同源 /api，不能只上传网页就得到可用的生成和下载服务。

### 推荐路线

1. **当前电脑/店内 demo**：继续 Node + 浏览器全屏，主入口 start-photo-booth.cmd。电脑用 localhost，手机同 Wi-Fi 取图。不需要公网部署。
2. **公开演示或手机离店后取图**：先改造部署边界。可用一台带持久磁盘的云服务器运行应用；添加 HTTPS、管理登录、设备认证、调用限额，调整 localhost 限制与取图域名。图片建议使用私有对象存储，通过短期授权链接交付。
3. **坚持 Vercel 前端**：Vercel 放页面；另配后端任务服务、数据库和对象存储，并处理同源 API 代理/跨域与身份认证。Vercel 不能访问用户电脑的 localhost 后端。

真实摄像头的云端页面需 HTTPS；浏览器仍从运行页面的设备获取摄像头。正式微信支付必须由服务端验证支付回调后解锁，不能沿用公开的模拟支付接口。当前未进行公网部署。
