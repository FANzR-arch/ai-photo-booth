# 线下触屏拍照亭

## 当前目标

电脑真实摄像头 → 选择照片并同意上传 → Seedream 图生图 → 相纸编辑与打印 → 手机扫码下载成片与原片。程序内无付款环节（现场先收费）。每次生成一张，下载复用生成结果，不再次调用 API。

主入口为 `start-photo-booth.cmd`。已有密钥留在本机服务端。`start-demo.cmd` 仅用于不调用 API 的流程演示；正常运营不显示测试照片按钮，需在工作台「模式切换」中选择「测试模式」。

## 设备界面

- 待机：标题、四步说明（选主题 · 拍一张 · AI 生成 · 取照片）、自动轮播大图（点图片也能开始）、开始拍照。顾客界面不显示设置入口，工作人员长按左上角标志 3 秒进入。生图服务未配置时显示“暂停服务”，不让顾客开始（现场先收费，避免收费后才发现无法出图）。
- 主题：填满可用屏幕，原生上下滑动浏览全部主题；横屏四列，窄横屏三列，竖屏和手机两列。统一 3:4 封面与标题区。每个内置主题有青年女性、成年男性、银发女性和儿童四张参考图，6.5 秒切换、800ms 淡入；支持暂停，触摸、焦点操作、后台标签页及减少动态效果偏好时暂停。自定义后台封面继续优先使用。
- 拍摄：选完主题自动申请摄像头；有可播放画面才允许倒计时拍照。三条短提示（站位、入镜、表情）代替段落，按钮下注明“拍完可以重拍”。倒计时期间隐藏顶部按钮。权限拒绝、无设备、占用、断开各有恢复提示。
- 确认：比例与服装两组二选一；同意勾选、“重新拍一张”和“开始生成”固定在同一操作区，一屏可见。
- 生成：左侧原照片（柔光扫过、阶段字幕、“已等待 N 秒”，不倒计时），右侧按主题分类自动选的小游戏：人像等为翻牌配对（吉签牌）、情侣/婚礼/生日为给原片贴贴纸、儿童为抓拍。开场“收到！”→ 抽上镜签（儿童不抽）→ 游戏；45 秒浮出“先挑个边框”，60 秒提示“照片不会丢”并换玩法；照片好了游戏自动谢幕，原片翻转成拍立得显影，再进入结果页。失败时“免费重新画一张”。设计过程见 `docs/等待体验-1-调研.md`、`-2-方案.html`、`-3-设计.html`；插画素材在 `assets/wait/`（WebP）。生成页没有返回按钮。
- 界面风格：同一套页面两种皮肤，“奶油珊瑚”（默认）和“孟菲斯波普”（`apps/web/src/skins/memphis.css`，黄底、黑描边、硬投影）。工作人员长按左上角标志 3 秒，在设置里按机器选择；网址加 `?skin=memphis` 可临时预览，不保存。新增页面元素时两种皮肤都要检查。
- 结果：相纸选择（缩略图直接显示本人照片）、一键留念文字（无键盘输入）、下一步取图。取图页：二维码、打印、“完成”与“再拍一张”。“本轮照片库”只在已有其他照片时出现。
- 更换主题或结束：释放摄像头、清空当前屏幕照片。切换运行模式不恢复另一模式的旧会话。

## 为什么继续用浏览器

当前本地 Node 服务配合浏览器全屏即可演示，不需要公网部署。电脑用 localhost / 127.0.0.1 获取摄像头，手机通过同一 Wi-Fi 访问取图页。正式落地可用浏览器 kiosk 模式启动；专用相机或打印一体机确定后再评估设备驱动和桌面封装。

## 实机验收

1. 打开电脑本地页面，开始并选主题，允许摄像头，确认实时取景和倒计时拍摄。
2. 确认本人的照片并提交，检查真实生成结果和用时。
3. 点击打印确认出纸；手机连接同一 Wi-Fi，扫码打开相册并下载，检查手机相册中的照片。
4. 返回首页检查摄像头停止，下一次体验没有上一位的照片。

自动测试使用模拟媒体和 API 响应，不能代替上述验收。浏览器连接已恢复，主题图库已进行横屏及竖屏视觉检查。真实人像图生图与物理手机下载仍待实测。内置角色图由 imagegen 生成，仅为风格参考，不是 Seedream 本人实拍结果。
