# Mac 直接打印

生成照片 → 选边框、编辑文字 → 点击「打印照片」。服务端合成完整成片，通过 macOS CUPS 提交到选定队列，不打开系统打印对话框，不要求付款。

## 首次配置

设备设置 → 打印机：启用打印，选择队列、相纸尺寸、纸型、质量、张数和照片适配，核对实际装纸后勾选确认并保存。保存只改变本应用配置，不改变系统打印默认值，不提交测试页。

当前现场队列为 EPSON_L805_Series，纸张尺寸尚未确认。不要把系统默认 A4 当成已装纸。选项来自当前 Mac 驱动；驱动无法提供纸张选项时停止配置，不猜规格。默认每次 1 张、完整保留并留白居中；裁切铺满可能裁掉边框、文字或人物。

设置保存在项目 data/printer-settings.json。不同 Windows/Mac 驱动选项不通用，仅在接有打印机的 Mac 启用。演示模式也只有明确点击打印才提交，不在生图完成时自动出纸。

## 任务与失败处理

每张生成照片只提交一次（份数依设置）。重复点击、刷新和重新打开照片不会多次出纸；边框或文字在点击前的已保存版本用于该次打印，不打印低清预览。

提交前失败可以重试；提交超时、服务中断或返回无法识别时标记“结果不确定”，不能自动重打。系统设置 → 打印机与扫描仪 → 对应打印机 → 打印队列，可处理缺纸、卡纸、离线和暂停。

“已提交打印”只表示 CUPS 接受任务，不代表纸已实际出来。首版没有自动故障重打和实体出纸传感确认。应用照片到期仍按原规则清理；已经交给系统的打印任务由 CUPS 管理，到期不会自动取消，维护人员应处理卡住的队列。

临时合成图保存在 data/print-jobs，提交结束后删除；异常退出遗留文件下次启动清理。任务状态保存在现有 SQLite 的 print 记录，不包含完整照片或 API 密钥。打印接口仅本机可用，后台配置必须登录。

## 更新与现场验收

按 README-Mac.md 停服、备份、更新与构建。现场如保留有未推送的 5e4bb99 计时提交，先保留该提交再合并 origin/main；不要 reset --hard，也不要覆盖计时改动。完成后用原桌面入口手动启动，不设开机自启。

自动化使用替身打印命令，覆盖驱动选项、合成图、权限、防重复、重启和失败。开发机不能验证 EPSON 实体出纸；现场确认相纸后，由用户点一次打印验证尺寸、边框、颜色与张数。

2026-09-30 开发验证：独立发布副本构建通过，128 项自动化测试通过；浏览器已验证设置保存、选边框/文字后提交、任务状态显示。使用合成图片和替身 CUPS 队列，未提交实体打印。
