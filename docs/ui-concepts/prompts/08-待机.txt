Use case: ui-mockup

横屏触屏自助 AI 拍照机的界面设计稿，画面比例 16:9（1920×1080），正面平视的完整屏幕截图，不要显示设备外壳、手、桌面或透视角度。商场/景区里的顾客站在一米外操作，所以字大、按钮大（主按钮高度明显大于普通网页按钮），一屏只有一个最醒目的主操作，没有多余文字和小按钮。品牌名“咔嚓！SNAP CLUB”放在左上角，字很小。界面里的照片使用真实感的亚洲人像写真样片（成人、情侣、儿童都可以），人物自然、不夸张。界面上只出现下面引号里给定的中文文字，不要出现其他文字、乱码或英文占位符。高保真 UI 设计稿质感，像 Dribbble 上的精品作品。

风格设定：米白新闻纸底色，黑色加一个正红色强调；超大号标题文字和照片大胆裁切叠压，像时尚杂志封面和内页排版；细线分栏、页码、期号这类排版元素（只用给定文字，装饰可以用纯线条和色块代替文字）；高对比、有质感、有设计感。

左侧大标题两行“今天，”“留张好照片。”，其中“好照片”用强调色；标题下一行四个带序号的小步骤“选主题”“拍一张”“AI 生成”“取照片”；下面一个很大的主按钮“开始拍照”。右侧约占屏幕一半是样片展示区：一张杂志封面式的大幅人像，大标题文字压在人物后面，旁边两张小图像内页排版。

单张独立完整待机界面，横向16:9，目标1920×1080。只呈现最终界面，不做多页面拼图，不加风格编号、说明或水印。允许文字仅为：咔嚓！SNAP CLUB、今天，、留张好照片。、选主题、拍一张、AI 生成、取照片、开始拍照，以及步骤序号1、2、3、4。若样片需要主题标签，仅从源文档给定名称中选用：奶油柔光、清透白场、窗边晴日、银盐肖像、电影主角、职场高光、奶油双人、恐龙探险队、小小列车长、海岛写真。装饰不增加未给定文字。
