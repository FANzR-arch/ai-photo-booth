Use case: ui-mockup
生成一张横屏触屏自助AI拍照机的完整待机界面设计，目标1920×1080、16:9。画面四边就是屏幕内UI四边，正面平视无透视，禁止设备外壳、真实桌面、画框外部环境、手指操作和提案说明板。高保真、精致且可信的真实产品待机使用状态，所有装饰都属于屏幕内平面图形。照片为真实感亚洲人物摄影。主标题大、主按钮很大，站在一米外能辨认；一个最醒目的拍照主操作。不要版权标志、水印、界面风格名称或“示例”“模拟”等字样。
保留品牌，左上角小字精确写“咔嚓！SNAP CLUB”。所有图片内可见文本严格限于下方提供的品牌、标题、说明、主按钮和四步骤，不增加任何标签、编号、装饰字母、乱码或随机小字。图形可以装饰，图形内不要文字。

本组视觉与构图：
漫画分镜与实拍人物混合的视觉，奶白纸、墨黑、番茄红 #E34A36、少量天空蓝。清晰手绘黑线、半色调网点、放射线和气泡框，但不要出现任何额外拟声词或字母。主标题在左侧巨大的浅色对话气泡中，粗黑中文，主按钮是左下红色的巨大圆角矩形，白字。右侧像漫画页面的三块不规则分镜格，一张主导的大幅真实亚洲成年女性半身照，另两格是成年朋友开心合照与男性人像；人物照片保持真实摄影，局部背景可以变成网点，不把人物变成漫画。四步骤在底部形成四格黑线小条。要清楚、有故事感、适合合照，不使用上一轮孟菲斯的几何彩纸拼贴。

本组精确文案：
主标题两行：“你的故事，”“现在开场！”。
副文案仅一行：“从一张照片，开启今天的故事。”。
唯一主按钮：“拍我的主角照”。
四个步骤按顺序精确写：“选风格”“拍照片”“AI 生成”“取照片”。
这些是产品文字，不要将本提示词的标签、风格名称或解释写入图中。
