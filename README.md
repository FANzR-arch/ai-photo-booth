# 咔嚓！AI 拍照亭 Demo

用于 Windows 电脑和触屏设备的内部演示，使用 **Seedream API** 真实生图。

**流程：** 选择主题 → 拍照或上传 → AI 生图 → 解锁 → 手机扫码取图。

## 启动

- **演示包：** 完整解压，双击 `启动拍照亭.cmd`，浏览器自动打开；无需安装 Node 或依赖。
- **源码：** 安装 Node.js 24+，复制 `.env.example` 为 `.env` 并填写密钥，运行 `start-photo-booth.cmd`。
- 电脑需要联网。手机取图需与电脑连接同一 Wi-Fi，电脑保持运行。

## 当前状态

拍照、生图、取图流程已实现；真实 API 生图与下载已测试。实际摄像头及手机使用需在目标设备确认。

主题库包含 21 个已启用风格，均附本地预览图。首页轮播使用全部已启用风格，支持前后切换和暂停；关闭的主题不参与轮播。在水彩、波普、炭笔和油画基础上，再补充水墨、剪纸、黏土、羊毛毡、像素、孔版印刷、蓝晒、彩绘玻璃、马赛克和低多边形 10 个方向。新增预览为原创风格示意，尚未逐项验证 Seedream 的人像重绘效果。风格及提示词以 `config/styles/styles.json` 为准；重启服务会补入新主题，并保留工作台中的已有修改。

生成等待页保留本次拍摄或上传的原照片，显示轻微扫光、等待秒数与状态提示。失败时保留原图并停止动画，结束体验时清空。刷新页面可恢复任务和原照片预览，原图通过仅本机的会话接口读取。详见 [新增风格与等待预览](docs/新增风格与等待预览.md)。

结果页为「免费原照片 + 一张生成图」：原图可直接免费保存，生成图单张 ¥9.90，原图不计费。拍照亭默认只生成一张，旧 `IMAGE_COUNT` 配置不再生效。品牌图标采用 [Lucide Camera](https://lucide.dev/icons/camera)（ISC，许可证保存在 `assets/licenses/LUCIDE-LICENSE.txt`）。

**尚未接入真实支付。** 页面只保留模拟解锁，支付方式后续根据门店实际情况接入。
