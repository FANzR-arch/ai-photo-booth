# 咔嚓！AI 拍照亭 Demo

用于 Windows 电脑和触屏设备的内部演示，使用 **Seedream API** 真实生图。

**流程：** 选择主题 → 拍照或上传 → AI 生图 → 解锁 → 手机扫码取图。

## 启动

- **演示包：** 完整解压，双击 `启动拍照亭.cmd`，浏览器自动打开；无需安装 Node 或依赖。
- **源码：** 安装 Node.js 24+，复制 `.env.example` 为 `.env` 并填写密钥，运行 `start-photo-booth.cmd`。
- 电脑需要联网。手机取图需与电脑连接同一 Wi-Fi，电脑保持运行。

## 当前状态

拍照、生图、取图流程已实现；真实 API 生图与下载已测试。实际摄像头及手机使用需在目标设备确认。
