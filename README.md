# 咔嚓！SNAP CLUB · AI 拍照亭 Demo

> **当前阶段：内部演示。** 本机后端直接使用 `.env` 内配置的共享 Seedream API 密钥调用真实生成服务。尚未接入独立账号、额度分配或真实支付。API 密钥仅在服务端配置，不随源码提交，也不发送到浏览器；生成会消耗该密钥所属账户的额度。

项目用于 Windows 电脑或线下触屏设备演示：选主题 → 拍照/上传 → AI 重绘 → 模拟购买 → 手机取图。无需域名或云服务器，电脑需要联网生成，手机取图需要同一局域网。

首次克隆后需安装 Node.js 24+，复制 `.env.example` 为 `.env` 并填入自己的可用配置，然后运行 `start-photo-booth.cmd`。目前源码交接可用，一键免安装的 Windows 分发包尚未制作。仅体验模拟流程可运行 `start-demo.cmd`，不需要密钥。

当前 Windows 电脑 + 内置摄像头，运行一套前端操作、提示词管理和 Seedream 云端接入。主入口 start-photo-booth.cmd 使用真实摄像头和 Seedream API，每次生成一张；仅支付模拟。start-demo.cmd 是独立的无 API 演示入口。npm start 读取本机 .env。

## 启动真实拍摄体验

1. 安装 Node.js 24 或更新版本（当前开发电脑已有 Node 24）。
2. 双击 `start-photo-booth.cmd`。首次启动会安装依赖并构建页面，保持窗口打开；此入口固定为 Seedream、每次一张，读取已有密钥。
3. 浏览器打开 **http://localhost:4377**，按 F11 全屏。不要用局域网 IP 打开电脑拍照入口。
4. 待机轮播 → 开始拍照 → 选择主题 → 允许摄像头 → 拍摄／重拍 → 同意本次使用照片 → 生成 → 模拟购买 → 手机扫码。

拍照页可直接更换主题。返回主题选择时结束旧会话、关闭摄像头并清除旧照片；每次进入主题页都会重新读取后台配置。连接失败时可点“重新连接”。普通步骤 120 秒无操作回待机，生成阶段为 300 秒。

| 入口 | 地址 | 用途 |
|---|---|---|
| 拍照亭 | http://localhost:4377 | 完整体验 |
| 管理页 | http://localhost:4377/admin | 编辑风格和提示词、示例图，查看记录与配置状态 |
| 分阶段演示 | http://localhost:4377/stages.html | 功能路线、目录和每阶段验收点 |

摄像头无权限或被其他软件占用时，可使用已有的 JPEG/PNG 测试照片。请只使用有权处理的照片。取景与最终照片采用一致的镜像方向。

### 当前演示到底生成了什么？

`demo` 模式只对输入照片做饱和度等确定性效果处理，并保留 `DEMO - NOT AI GENERATED` 标识。它用于检查拍照、选图、购买和交付流程，**不代表 AI 换装、3D 化或 Seedream 成片质量**。待机轮播和主题卡片使用内置生图工具创作的意向素材，不是 Seedream 人像样片。主题图片统一 3:4，支持横屏、竖屏与触屏点击。

模拟支付按钮不会访问支付平台、不会扣款。单张 ¥9.90，两张全部 ¥19.90；如果只生成一张，全部也是 ¥9.90。模拟购买后解锁同一张已经保存的高清图，不再次生图。demo 高清图仍保留演示标识。

## 连接 Seedream

先读 `docs/seedream.md` 的来源与限制。

1. 项目迁移时已保留本机 `.env`。仅在文件不存在时，将 `.env.example` 复制为 `.env`；不要覆盖已有密钥。
2. 从自己的火山方舟账户取得 API 密钥和当前可用的图像编辑模型标识。
3. 在本机 `.env` 中设置：

```dotenv
GENERATION_MODE=seedream
SEEDREAM_API_KEY=你的密钥
SEEDREAM_MODEL=doubao-seedream-5-0-pro-260628
IMAGE_COUNT=1
PORT=4377
PICKUP_BASE_URL=
```

4. 使用 `npm start` 启动已配置模式，管理页应显示 Seedream 模式、配置就绪和每次 1 张。`start-demo.cmd` 始终为演示模式。
5. 在电脑拍摄，确认照片并勾选上传同意后提交。每次确认会真实调用一次 API；模拟购买不会再生成图片。

相邻 `seedream-test/result.json` 记录已验证单张文生图：`doubao-seedream-5-0-pro-260628`，`1.5K`，耗时 23.08 秒。该记录的输入图片数为 0，不能证明人像图生图、相似度或九类提示词已验证。当前后台不传组图和流式参数。本轮未追加 Seedream 付费调用。密钥仅保存在服务端，不发到聊天、前端或 Git。

选择 2 张时会按顺序调用两次，存在两次计费机会。连接超时、服务重启、5xx 或本地保存失败会保留未知状态，不自动重新提交。第二张失败保留第一张，不自动补图。错误和请求编号可在管理页查看。

## 手机取图

本机真实照片验收及 Vercel 部署判断见 [部署建议](docs/部署建议.md)。用户提供的约 30 MB 原片已通过浏览器上传、真实 Seedream 生成、模拟解锁及 LAN 下载；物理手机扫码仍需实测。大于 12 MB 的 JPG/PNG 现会在浏览器缩小后上传（原片上限 60 MB），不修改原文件。

- 手机和电脑需要连接同一 Wi-Fi。二维码指向电脑局域网地址。
- 管理页可看到自动选取的取图地址。如果电脑有多个网卡，请将 `.env` 的 `PICKUP_BASE_URL` 改为手机可访问的电脑 Wi-Fi 地址，例如 `http://192.168.1.20:4377`，然后重启。
- 软件不自动更改防火墙。若手机连接失败，先检查 Wi-Fi 是否隔离设备、Windows 私有网络是否允许此端口。
- 仅手机取图路由向局域网开放，电脑拍照入口、管理接口和原始照片不向手机开放。
- 取图凭证相当于这份相册的钥匙，请保存链接并避免转发。默认有效期为会话创建后的 24 小时。
- 服务运行时每分钟清理到期照片；关机期间不会清理，重启后补充清理。已到期链接返回过期提示。
- 微信内保存受限时可在手机浏览器打开。电脑关闭或手机离开该网络后，本版本取图链接无法继续访问。

## 风格与数据

九套风格位于 `config/styles/styles.json`：七套默认可用，城市和品牌主题需补齐占位内容后才能启用。已有三套提示词保持原配置，新增六套来自 `docs/Seedream照片风格提示词.json`。启动时仅向 SQLite 添加缺失的风格，不覆盖已有提示词、版本、开关或自定义示例图。运行中的配置以后台管理页为准；修改 JSON 不会覆盖已有记录。提示词编辑会增加版本，生成任务保存当时配置快照。

上传示例图必须是 JPEG/PNG。`data/` 保存 SQLite、原始照片、生成结果和预览，目录不会作为静态站点公开；它和 `.env` 已被 `.gitignore` 排除。订单和配置元数据保留在数据库，图片有效期不代表订单元数据也删除。

## 开发与检查

```sh
npm install
npm run dev
npm run build
npm test
npm start
```

开发页面位于 http://localhost:5173，后端仍为 4377。手机取图使用构建后的 4377 页面，因此测试手机前先构建。不要同时运行两个监听 4377 的服务。默认启动脚本每次构建，以避免看到旧前端。
