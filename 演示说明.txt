咔嚓！AI 拍照亭 — 内部演示版

【如何启动】
Windows 10/11 64 位电脑：先把 ZIP 完整解压到普通文件夹，再双击“启动拍照亭.cmd”。
包内已带 Node 运行环境、依赖、页面和完整项目源码，不需要安装开发工具。
浏览器自动打开；请允许摄像头权限。使用期间保持启动窗口开启，关闭窗口即停止服务。
如果浏览器没有自动打开，请复制启动窗口显示的完整地址到浏览器。每次启动的端口会自动分配。

【当前功能】
2026-09-17 更新：21 种主题预览、主题卡片飞入、页面柔和过渡，生成等待时保留原照片。
每次生成一张效果图，模拟购买价 ¥9.90；原照片免费，可在电脑端保存。
当前使用 Seedream API 进行真实 AI 生图，电脑需要联网。
拍照、AI 生图、解锁及获取图片的完整演示流程已实现，可使用摄像头，也可上传照片。
已用真实人像完成生图、模拟解锁和下载测试；摄像头及手机扫码需要在同事的实际设备上确认。
流程：选择主题 → 拍照/上传 → 确认生成 → 查看效果 → 模拟解锁 → 手机扫码取图。

【手机取图】
手机与电脑连接同一 Wi-Fi，扫描页面二维码即可打开相册并下载。
首次启动如 Windows 提示防火墙权限，请仅在可信的私有网络允许访问。
公司/访客 Wi-Fi 如果隔离设备，手机可能无法连接，建议换到允许设备互通的网络。
电脑需要保持运行；照片默认保存 24 小时，请及时下载。不需要域名或云服务器。

【演示 API】
本演示包的 .env 已配置内部演示用 Seedream API，由本机后端调用。
生成会消耗该账户的 API 额度；模拟支付和下载不会再次生图。
仅供内部同事使用，请勿公开上传或转发带有密钥的演示包。
本包不包含此前测试的个人照片和数据库；新照片在本机 data 文件夹保存。

【常见情况】
摄像头不可用：允许浏览器权限，关闭占用相机的软件，再重新连接；也可上传照片演示。
重复启动：每次都启动当前演示包的新实例，自动分配空闲端口，无需关闭旧页面。
不同实例的照片和配置记录独立保存于 data/instances；旧的取图链接需要对应实例保持运行。每次新启动使用包内默认主题配置。
生成失败：查看页面提示，检查网络、API 配额和模型权限。结果不确定时不要反复提交。
系统提示脚本或程序被阻止：交由同事所在单位的设备管理员按实际策略处理。
