用一台电脑，把灵感变成一张照片。这里是功能路线入口。云端生图需要配置 Seedream。

打开拍照亭 ↗打开管理页 ↗
选风格→拍照 / 重拍→生成→水印预览→照片选择→手机取图
01

功能梳理

设备端负责拍照与选择；管理端负责风格和调用记录；手机端仅交付已解锁图片。失败可恢复，未知结果不盲目重试。

说明：当前页面 + docs/功能梳理.md
02

结构与启动

apps/web       拍照亭 · 管理页 · 手机取图
apps/server    生成任务 · 订单 · 安全下载
packages/shared  共用接口类型
config/styles  3 套风格配置
assets/examples  本地插画示例
data           私有照片与 SQLite（不提交）
docs           操作说明与验证记录
说明：启动服务后，管理页可查看当前模式和配置状态。
03

趣味拍照亭前端

从风格卡片进入真实取景，倒计时拍照、重拍、等待、选图。无摄像头时可以上传经授权的测试照片。

说明：支持本机处理与云端生成。
04

提示词 + Seedream API

电影人像、商务肖像、3D 卡通三套提示词可编辑。API 密钥只存后台。生成耗时和错误可查看。

真实样片：需配置密钥、模型并确认测试预算和照片授权；尚未配置不视为完成实测。
05

照片选择 + 手机取图

先看带水印预览，解锁已有高清图。二维码只指向该订单已购买的图片；手机与电脑连接同一 Wi-Fi。

解锁后即可下载高清照片。
06

连续体验与异常恢复

验证重复提交、刷新、到期、两位用户隔离，以及失败恢复。摄像头与手机实机结果单独记录。

最终证据见 docs/验证记录.md。
