# Mac 安装与日常使用

适用 Apple 芯片 Mac。仓库：https://github.com/FANzR-arch/ai-photo-booth ，分支 `main`。

## 日常使用

1. 双击桌面 **启动拍照亭.command**，自动打开浏览器中的拍照首页，优先使用 Chrome。
2. 点击 **设备设置**。首次输入一个至少 8 位的密码并点击 **设置并解锁**；以后输入这个密码即可解锁。
3. 在 **生图服务** 填入自己的 Seedream API 密钥和模型 ID，点击 **保存配置**。立即生效，返回拍照亭即可使用，无需重启或切换模式。

密码、API 和数据保存在本机，下次不用重新配置。没有 API 时也能启动页面，生成按钮等待配置完成；不会自动使用演示图片代替真实生成。保存配置不请求供应商，实际点击生成才会使用 API 额度。

启动窗口可以最小化，保留窗口即可持续运行；在窗口按 Control+C 停止。关掉浏览器不会停止服务，再次双击桌面图标会打开现有服务。**没有开机或登录自启**。程序运行时阻止闲置睡眠，但合盖、注销、断电后不保证继续运行；营业时保持开盖供电。

固定使用 `.env` 中的 PORT（默认 4377）和项目 `data/`。摄像头拍摄与后台设置应在本机 localhost 打开。手机同一 Wi-Fi 可取图。

## 由现场 AI 安装或更新

把 [部署提示词](docs/Mac-AI-部署提示词.md) 交给现场 AI。安装人员完成一次准备后，使用者不需要终端配置。

首次安装：

```bash
mkdir -p "$HOME/Applications"
git clone --branch main --single-branch https://github.com/FANzR-arch/ai-photo-booth.git "$HOME/Applications/ai-photo-booth"
cd "$HOME/Applications/ai-photo-booth"
bash install-mac.command
```

安装器在项目 runtime 内下载官方 Node v24.15.0 arm64 并核对 SHA-256，按锁文件安装依赖、构建、验证 sharp 与 SQLite，自动创建桌面快捷方式。不需要 sudo，不修改系统 Node。首次需要 GitHub、nodejs.org、npm 网络访问。

已有安装的更新步骤：

1. 等待使用结束，正常停止本项目服务。记录提交号，检查工作区；保留现场改动，不强制覆盖。
2. 把 `.env` 和 `data/` 备份到仓库外仅当前用户可读的目录，勿输出密钥和照片。备份照片沿用原保留期限。
3. 确认 origin 为本仓库且分支 main，执行 `git pull --ff-only origin main`。
4. 运行 `bash scripts/macos/prepare.sh --update`，完成停止和备份检查后输入 `UPDATE`。自动重建并创建桌面入口，保留配置。
5. 用 macOS `open "$HOME/Desktop/启动拍照亭.command"` 让系统 Terminal 启动服务，检查实际页面和 `/api/health`。不要用 AI 沙箱子进程代替用户的长期运行窗口。

快捷方式丢失时，运行 `bash scripts/macos/install-shortcut.sh` 重建。遇到其他同名桌面文件会停止而不覆盖。准备失败时保留错误，修复后重跑；不跳过下载校验。

回退时先停止服务，在独立目录检出记录的旧提交，恢复与该版本配套的配置和数据，再构建运行。

## 维护与设备

`mac-booth.command` 保留为维护菜单：1 免费演示（随机端口、独立数据）；2 终端配置 API（此维护方式需重启已有服务）；3 严格检查配置后启动真实模式；4 只读设备诊断；5 忘记密码时重置。**这些菜单不是日常启动步骤。**

工作台首次设置密码仅允许本机且检查来源，已设置后不能再次认领。密码用 scrypt 哈希保存在 `data/admin-auth.json`，不是明文。后台闲置 10 分钟锁定，登录最多 8 小时；重启、重置密码和退出使登录失效。API 仅返回掩码，留空保留已有密钥；生成进行中拒绝修改。

工作台“拍照摄像头”可主动预览、选择 UGREEN 并保存。需现场人员遮挡外接镜头确认来源。摄像头权限由系统授权；选择按浏览器和网址保存，不跨随机端口。指定设备失效时不会静默切到内置镜头。

菜单 4 只读采集打印队列、驱动、纸张与选项，不消耗纸墨。EPSON L805 驱动默认 A4 不代表实际装纸。打印参数与实物出纸仍需现场核实。

照片结果页已支持点击「打印照片」直接提交到 Mac 打印队列。首次需确认实际相纸并在后台启用，见 [Mac 直接打印](docs/Mac直接打印.md)。当前支付仍为模拟，公网取图未接入；实体出纸尚需现场验收。
